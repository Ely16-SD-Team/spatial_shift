
MindShift

A 2D shooter focused on spatial reality shifting, inspired by classic Flash games, created by SD-Team for Restless Jam 2 (+ Prizes) (2026).

Game Features

• Shifting Reality — the environment transforms into its true, real version.

• The Vibe — the authentic feel of old, jittery Flash games.

• Frameless Animation — character movement and other animations are made using just a single frame.


Tech Stack

• Engine: GameMaker Studio 2 (standard public Steam version).
• Language: GML (GameMaker Language).

How to Open the Project

1. Clone the repository or download the source code archive:bash
git clone https://github.com/Eternally-EGS/spatial_shift.git
Use code with caution.
2. Open GameMaker 2.
3. Click Open and select the spatial_shift.yyp file from the repository folder.
4. Press F5 to run a test build.
